# Sounds

From the *Universal UI Soundpack* by Nathan Gibson
(https://nathangibson.myportfolio.com), licensed under
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

Changed for the shell by `scripts/build_sounds.py`: cut to what can be
heard, filtered (high- and low-pass), brought to one loudness, faded out,
and in `connect`, `disconnect` and `eject` two or three of the pack's sounds
played after each other. Which pack sound each file comes from is listed in
that script.
